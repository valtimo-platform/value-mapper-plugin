# Release notes

Overzicht van wijzigingen per versie van de Value Mapper-plugin.

## 6.0.0
Geschikt gemaakt voor Valtimo 13.24.0 en ondergebracht in een eigen repository, met voorbeeldapplicatie en aparte documentatie.

## 5.0.0
Geschikt gemaakt voor Valtimo 13.

## 1.3.0
Een standaardwaarde kan nu ook zonder transformaties worden meegegeven, zodat een doelveld altijd gevuld kan worden.

## 1.2.0
Het is nu mogelijk om commando's of transformaties voorwaardelijk over te slaan.

## 1.1.0
Verbeterde voorinvulling van processen met behulp van de Value Mapper.

## 1.0.0
Eerste publieke release: waarden kopiëren van een bron-JSON naar een doel-JSON met optionele transformaties.
