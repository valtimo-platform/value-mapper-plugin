# Release notes

Overzicht van wijzigingen per versie van de Value Mapper-plugin. Backend (`com.ritense.valtimoplugins:valuemapper`) en
frontend (`@valtimo-plugins/value-mapper`) worden onder hetzelfde versienummer uitgebracht.

## 2.0.2

Valtimo bijgewerkt naar versie 13.41.0.

## 2.0.1

`BadRequestAlertException` is in Valtimo verplaatst van `com.ritense.valtimo.web.rest.error` naar
`com.ritense.valtimo.contract.web.rest.error`. 

Daarnaast bijgewerkt naar Valtimo 13.37.0

## 2.0.0

De plugin is uit de monorepo gehaald en heeft een eigen repository gekregen, met voorbeeldapplicatie, eigen
documentatie en eigen publicatie-workflows voor backend en frontend.
